# 장바구니 FE+BE 미션 리뷰어 가이드

# 4단계

[리뷰 포인트]

1. 인터페이스가 구현을 숨기는가?

- 호출부에서 내부 구조를 알아야만 이해되는 매개변수가 있는가?
- 컴포넌트, 훅, 함수에서 불필요한 매개변수, 반환값이 없는지 확인하고 리뷰한다.

2. 테스트 범위를 스스로 정의하고 이유를 설명했는가?

- 왜 이 테스트를 선택했는지 PR에 근거가 있는가?
- 쿠폰 도메인 로직(경계값, 복합 조건)이 테스트로 명세화되어 있는가?

3. 서버 응답과 클라이언트 상태의 책임이 분리되어 있는가?

- 서버 응답을 SSOT 로 유지하고 있는가?
- 불필요한 클라이언트 상태는 없는가?
